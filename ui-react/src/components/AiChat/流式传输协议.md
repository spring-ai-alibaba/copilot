# 流式传输协议文档（AG-UI）

## 📋 协议概述

后端从 spring-ai-alibaba 迁移到 agentscope 2.0 后，聊天流式交互改用 **AG-UI 协议**。
后端用 `AguiAgentAdapter` 把 agentscope 的 `AgentEvent` 流（`streamEvents()`）转成标准 AG-UI 事件，
通过 `/api/chat`（SSE，`text/event-stream`）下发；前端用 `useChat` + 自定义 `fetch` 解析 SSE 帧。

### 为什么换

- 旧框架（spring-ai-alibaba ReactAgent）在工具调用阶段**不流式**——工具参数、结果整块吐出。
- agentscope 2.0 的 `streamEvents()` 产出细粒度事件：`TOOL_CALL_DELTA`（工具参数增量）、
  `TOOL_RESULT_TEXT_DELTA`（工具结果增量）、`TEXT_BLOCK_DELTA`（文本增量），工具调用全程流式。

### SSE 帧格式

```
event: <UPPER_EVENT_TYPE>
data: <json>

```

- `event` 字段 = AG-UI 事件类型枚举名（UPPER，如 `TEXT_MESSAGE_CONTENT`）。
- `data` 字段 = 该事件的 JSON（含 `type`、`threadId`、`runId` 及事件特有字段）。

## 🔌 事件清单与前端映射

| AG-UI 事件 | 关键字段 | 前端处理 |
|---|---|---|
| `RUN_STARTED` | threadId, runId | 标记本轮开始（暂不渲染） |
| `TEXT_MESSAGE_START` | messageId | 文本块开始 |
| `TEXT_MESSAGE_CONTENT` | delta | **累积 delta 拼入聊天正文**（喂给 AI SDK text 流） |
| `TEXT_MESSAGE_END` | messageId | 文本块结束 |
| `TOOL_CALL_START` | toolCallId, toolCallName | 记录工具调用状态（name） |
| `TOOL_CALL_ARGS` | toolCallId, delta | **累积 args JSON 片段**（按 toolCallId） |
| `TOOL_CALL_END` | toolCallId | 解析完整 args → 驱动文件操作（见下） |
| `TOOL_CALL_RESULT` | toolCallId, content | 工具结果字符串（list/grep 等，暂仅日志） |
| `RUN_FINISHED` | threadId, runId | 注入 `data: [DONE]` 结束 AI SDK 流 |
| `RUN_ERROR` | message | 错误日志 |
| `REASONING_*` | delta | 思考链（阶段2 接入渲染） |

### 控制事件（非 AG-UI，后端额外下发）

| event | data | 处理 |
|---|---|---|
| `conversation-id` | `{conversationId}` | 写入 `useConversationStore.setCurrentConversation`（支撑多轮） |
| `complete` | `[DONE]` | 流结束（emitter.complete） |

## 🛠 工具调用 → 文件操作映射

`TOOL_CALL_END` 时解析累积的 args JSON，按 `toolCallName` 分发：

| 工具名 | args 字段 | 前端行为 |
|---|---|---|
| `write_file` | path, content | `StreamingFileManager.addContent(path, content)` 打字机渲染到编辑器 |
| `edit_file` | path, old_string, new_string | `addContent(path, new_string)` + 完成后校准 |
| `delete_file` | path | `useFileStore.deleteFile(path)` |
| `list_files` / `grep_files` / `glob_files` / `read_file` | path, … | 结果走 `TOOL_CALL_RESULT.content`（暂不渲染到聊天） |

文件路径经 `normalizeFilePath` 规范化（统一分隔符、去 `workspace/` 前缀）。

## 📡 请求

`POST /api/chat`（SSE），body 为现有 `ChatRequest`：
```jsonc
{
  "message": { "content": "..." },     // 单条用户消息
  "modelConfigId": 123,                 // 动态模型配置 ID
  "conversationId": "uuid 或省略",      // 省略则后端新建
  "tools": [...],                       // MCP 工具（阶段3）
  "enablePreferences": true,
  "enablePreferenceLearning": true
}
```

后端把 `conversationId` 作为 AG-UI `threadId`（供会话历史 Middleware 定位，阶段2），
`modelConfigId` / 偏好开关放进 `forwardedProps`。

## ⚠ 阶段说明

- **阶段1（当前）**：单轮流式 + 文件操作打字机渲染已跑通。工具调用全程流式（`TOOL_CALL_ARGS` delta）。
- **阶段2**：会话历史/长期记忆 Middleware 接入（多轮历史还原、用户画像注入）。
- **阶段3**：知识库 embedding 换 agentscope rag-simple；MCP 换 agentscope McpClientBuilder。
